以下の小説本文を注意深く読み、描写からキャラクター設定として確定的に読み取れる情報を、登場する全キャラクター（新規キャラクターを含む）について抽出せよ

# 出力形式

- 出力はスキーマに適合するフラットな `updates` 配列のみとする。キャラクターごとにネストしたオブジェクト構造を作らない
- `text` は必ず単一の文字列とする。オブジェクト・配列・null を入れない

出力例（形式の参考。内容は本文から抽出すること）:

{
  "updates": [
    { "name": "ジェフ", "attribute": "personality", "text": "冷静沈着で、部下からの信頼が厚い。" },
    { "name": "ジェフ", "attribute": "expression", "text": "タメ口。一人称は俺。語尾は〜だ。「行くぞ」「心配するな」" },
    { "name": "ジェフ", "attribute": "aliases", "text": "クライン艦長、ジェフリー" }
  ]
}

# name の規則

- name と aliases は「人物」のみ。艦船・兵器・組織・部隊・地名・国名など、人物以外の固有名詞をキャラクターとして登録しない
- name と aliases には読み仮名・ルビ・ローマ字・括弧書きの説明を付加せず、本文の表記をそのまま使う
- 同一人物が本文中で複数の呼称で登場する場合は1人に統合し、name 以外の呼称はすべて aliases にまとめる
- 同一人物の呼称の中から、もっとも具体的かつ個人を特定出来るものを選んでnameとする。愛称・名のみ・姓のみ・役職・肩書・人間関係などはaliasesとする
- 複数人でnameが重複した場合には、記述量が少ない方がそれを避けてaliasesの中から次にふさわしいものをnameとする

# 発話者の特定

- セリフの発話者は、前後の地の文の帰属表現（「〜が言った」等）・呼びかけ・口調・会話の応答関係から慎重に特定する
- 発話者を確信できないセリフは、引用にも性格・口調の判断根拠にも使わず、設定に加えない。

# 制約

- attributeの値は "role", "appearance", "personality", "expression", "background", "relationship", "weakness", "style", "aliases" の中からのみ選ぶこと
- text には本文に直接根拠となる記述が確認できる情報だけを書くこと。推測・創作・補完・物語外の知識による補足は禁止
- 1キャラクターについて複数のattributeを抽出してよい
- 各attributeについて複数の内容を抽出してよい
- 1キャラクターについてattribute間で重複する内容はなるべく避ける
- personalityは本文の描写・行動・発話から読み取れる性格・気質を本文の語り手視点・他キャラクターの評価・当人の発話の三つの観点を統合し1〜2文で簡潔に記述する
- expressionは口調の特徴を必ず記述すること。特徴の説明には具体例は含めず、鍵括弧を使わない。以下の観点を含める：
  - 敬語 / タメ口 / 命令調の別
  - 一人称（「私」「俺」「僕」「うち」「あたし」等）
  - 文末語尾の特徴（「〜わ」「〜ね」「〜だ」「〜ぞ」「〜かしら」等）
  - 性別・立場・社会的特徴（丁寧語・粗野な言葉・貴族的口調等）
- expressionには、本文に登場する代表的なセリフを1〜4本、原文のまま改変せず引用する
  - 各セリフは鍵括弧で囲い、口調の特徴と区別がつくようにする。一字一句変えずに引用し、要約・言い換え・合成は禁止
- text の先頭に属性名のラベル（「口調：」「呼称：」等）を付けず、内容のみを書くこと。属性名は attribute フィールドで既に指定している
- aliases の text は呼称のみを「、」区切りで列挙すること。説明文や地の文を含めない（例:「クライン艦長、ジェフリー」）
- 代名詞（「彼」「彼女」「あの人」等）のみで特定できる、固有名詞を持たない人物は記録しない
  - マイナーキャラクター（セリフのない通行人・使者・群衆の個人等）も、固有名称があれば漏れなく抽出する
- 本文に新しく登場したキャラクターも対象に含めること
- 本文から読み取れない属性は推測で埋めず、ただ無いとして扱って空値を返すこと
- 既存の設定が無くなっている場合、ただ描写されていない可能性も考慮する
- 既存の設定と矛盾する設定があっても、ただ以前に描写されていない可能性も考慮する
- 抽出が何もない場合は updates を空配列で返す
