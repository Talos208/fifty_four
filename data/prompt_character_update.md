# 制約

- 属性の値は "role", "appearance", "personality", "speech_style", "background", "relationship", "weakness", "style", "aliases" の中からのみ選ぶこと
- 1キャラクターについて複数の属性を抽出してよい
- 各属性について複数の内容を抽出してよい
- nameはそのキャラクターが本文中で最も頻繁・中心的に呼ばれている呼称（固有名詞を優先）
  - フルネーム・名・姓・あだ名・役職名・肩書きなど別呼称をすべてaliasesとして列挙
- personalityは本文の描写・行動・発話から読み取れる性格・気質を本文の語り手視点・他キャラクターの評価・当人の発話の三つの観点を統合し1〜2文で簡潔に記述する
- speech_styleは口調の特徴を必ず記述すること。以下の観点を含める：
  - 敬語 / タメ口 / 命令調の別
  - 一人称（「私」「俺」「僕」「うち」「あたし」等）
  - 文末語尾の特徴（「〜わ」「〜ね」「〜だ」「〜ぞ」「〜かしら」等）
  - 性別調・社会的登録（丁寧語・粗野な言葉・貴族的口調等）
  - 本文に登場する代表的なセリフを1〜4本、原文のまま改変せず引用する
    - 鉤括弧は外してよい。本文から一字一句変えずに引用し、要約・言い換え・合成は禁止
  - 本文中に発話がない場合は「地の文から推定：〜」と明記する
- text には本文に直接根拠となる記述が確認できる情報だけを書くこと。推測・創作・補完・物語外の一般知識による補足は禁止
- 既存設定に含まれない情報が断片的にしか無い場合も、既存設定を削除せず追加情報として扱うこと
- 代名詞（「彼」「彼女」「あの人」等）のみで特定できる固有名詞を持たない人物は記録しない
  - マイナーキャラクター（セリフのない通行人・使者・群衆の個人等）も、固有名称があれば漏れなく抽出する
- 本文に新しく登場したキャラクターも対象に含めること
- 本文から読み取れない属性は推測で埋めず、ただ無いとして扱う
- 既存の設定が無くなっている場合、ただ描写されていない可能性も考慮する
- 既存の設定と矛盾する設定があっても、ただ以前に描写されていない可能性も考慮する
- 抽出が何もない場合は updates を空配列で返す
