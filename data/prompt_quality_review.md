# 指示
小説の本文を読み、「AI が書いたような不自然な日本語」に当たる箇所を指摘せよ。文章の良し悪しの一般的な批評ではなく、下のカテゴリに該当する箇所だけを挙げること。該当がなければ `{"findings": []}` を返す。

## カテゴリ(category にはこの文字列をそのまま使う)
- 壮大化: ささやかな出来事や感情を「真理」「宿命」「境地」のような大きな言葉・普遍的な教訓にまで膨らませている。場面の終わりに抽象的な命題や教訓を付けている。
- 擬人化: 無生物・概念が人間の動詞を取って主語になっている(「沈黙が語る」「データが示す」「静寂が全てを物語っていた」)。誰が何をしたかを書けば済む箇所。
- 直訳の比喩: 英語の慣用句を直訳したような比喩(「静かに壊れる」「〜を運ぶ」「開かれた問い」「〜した瞬間」の多用)。日本語の小説として慣用化していない言い回し。
- 曖昧な比喩: 何を指すのか一意に決まらない比喩、慣用句をひねっただけの言い回し。
- 閉じ方の均一: 段落の最後を毎回「〜なのだと気づいた」「〜を痛感した」のように律儀に着地させている。
- テンプレ反復: 「具体的な出来事 → 心の声 → 抽象化」の型を何度も繰り返している。
- 遠い語り手: 「人は誰しも〜」「多くの人が〜」のように、登場人物の話を一般論へ逃がしている。
- 溜めの演出: 「そこには〜が潜んでいた」「果たして〜だろうか」のように、起伏のない内容へ構文だけで劇的な溜めや問いかけを作っている。
- 感情が一律に最大: 感情や評価がすべて最上級(「完璧」「圧倒的」「言葉を失う」)で、中間の温度が無い。

## 守ること
- 台詞(「」『』の内側)は診断しない。台詞は登場人物の口調である。
- 1箇所につき1件。同じ箇所を複数のカテゴリで重ねて挙げない。
- `paragraph` は対象の先頭に付いた `[P<番号>]` の番号をそのまま整数で書く。
- `quote` は**本文からの一字一句そのままの抜粋**(20字以内、1つの段落内に収まること)。言い換え・要約・省略記号は不可。本文に存在しない文字列は無効になる。
- `message` は何が問題かを1文(40字以内)で述べる。書き換え案は不要。
- 文体の好み(長短・硬軟)や、1度きりの自然な表現は指摘しない。迷ったら指摘しない。

出力は JSON のみとし、JSON 以外の文字を一切含めないこと。
