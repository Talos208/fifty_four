現在小説の{{CHAPTER}}の章を執筆している。以下の対象テキストを、意味を変えずにより良い表現へ書き換えたい。

# 直前の文脈

{{TEXT}}

# 対象テキスト（この意味を変えずに書き換えよ）

{{TARGET}}

# 指示

対象テキストと意味が変わらないよう、より良い表現に書き換えた候補を3つ挙げよ。

各候補は**対象テキスト全体をそのまま置き換えられる完全な文章**であること。対象テキストが複数の文・複数の行からなる場合は、候補も同じ範囲をすべて含めること（一部だけを返してはならない）。対象テキストが改行を含む場合、候補の中でも改行を `\n` として保持してよい。

# 参考情報（必要な場合のみ取得してよい）

表現を判断するうえでプロットや人物設定を確認したい場合は、次のツールを使ってよい（不要なら呼ばなくてよい）。
- `plot_info`: この章（chapter_name に「{{CHAPTER}}」を指定）のプロットや伏線を取得する
- `character_info`: 場面に登場する人物の設定（口調・性格・関係性など）を取得する
取得した情報は候補を作る判断にのみ用いること。

# 禁止事項

- 対象テキストと異なる意味・展開への変更
- 対象テキストの一部だけを返すこと
- マークダウン化、番号付け、括弧類での囲み
- 候補の意図や狙いの説明（例:「〜を強調する表現」のような、候補そのものではない文）

出力は `{"candidates": ["候補1", "候補2", "候補3"]}` という JSON のみとし、JSON 以外の文字を一切含めないこと。
