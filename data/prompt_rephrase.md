# 指示
対象テキストと意味が変わらないよう、より良い表現に書き換えた候補を挙げよ。
対象テキストが複数の文・複数の行からなる場合は、対象より短い・同じくらい・対象より長い、の3つの候補にすること。
対象テキストが1文かそれ以下なら、同じくらい、対象より長い、さらに対象より長い、の3つの候補にすること。

対象テキストを各候補で置き換えた結果として、候補ではなく**テキスト全体が完全な文章**であること。
対象テキストが改行を含む場合、候補の中でも改行を `\n` として保持してよい。

# 参考情報（必要な場合のみ取得してよい）
表現を判断するうえでプロットや人物設定を確認したい場合は、次のツールを使ってよい（不要なら呼ばなくてよい）。
- `plot_info`: この章（chapter_name に「{{CHAPTER}}」を指定）のプロットや伏線を取得する
- `character_info`: 場面に登場する人物の設定（口調・性格・関係性など）を取得する
取得した情報は候補を作る判断にのみ用いること。

# 禁止事項
- 対象テキストと異なる意味・展開への変更
- 対象テキストの一部だけを返すこと
- マークダウン化、番号付け、括弧類での囲み
- 候補の意図や狙いの説明（例:「〜を強調する表現」のような、候補そのものではない文）

出力は `{"candidates": ["候補1", "候補2", "候補3"]}` という JSON のみとし、JSON 以外の文字を一切含めないこと。
