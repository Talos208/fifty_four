= fifty_four - LSP サーバ
:toc:
:icons: font

tower-lspクレートを使用して実装されたLanguage Server Protocol (LSP)サーバです。

== プロジェクト概要

このプロジェクトは、Rustのtower-lspフレームワークを使用した基本的なLSPサーバの実装です。現在は初期化とシャットダウンのみの機能を持つ最小限の実装となっています。

== 必要な環境

* Rust 1.70以上
* Cargo

== 依存関係

* `tokio`: 非同期ランタイム
* `tower-lsp`: LSPサーバフレームワーク
* `serde`, `serde_json`: JSONシリアライゼーション

== ビルド方法

[source,bash]
----
cargo build
----

== 実行方法

[source,bash]
----
cargo run
----

サーバは標準入出力を使用してLSPクライアントと通信します。

== ACPエージェントとして起動する

同じバイナリに `--acp` を付けると、LSPサーバではなく
ACP (Agent Client Protocol) エージェントとして起動します。
Zedの Agent Panel から作者の相談相手として応答し、
その会話の要約をLSP側の短文生成のコンテキストとして渡します。

NOTE: `--acp` は **debug ビルド限定** です。`claude` CLI の
サブスクリプション枠をそのまま使うため、`--release` の配布物には
含まれません（`--acp` を渡すとメッセージを出して終了します）。

中身は Claude Agent SDK 経由の `claude` CLI なので、
プロット・キャラクター設定・メモの読み書きやWeb検索がそのまま使えます。
`ANTHROPIC_API_KEY` を設定していても無視され、
ログイン済みCLIのサブスクリプション枠で動きます（APIキーは不要です）。

[source,bash]
----
fifty_four_lsp --acp
----

コーディング向けの `CLAUDE.md` が混ざらないよう、
プロジェクトのものも `~/.claude/CLAUDE.md` も含めて読み込みを無効化しています。

Zedへの登録方法（`settings.json` の `agent_servers`）と設定項目は
link:docs/acp-agent.md[docs/acp-agent.md] を参照してください。
