= fifty_four - LSP サーバ
:toc:
:icons: font

tower-lspクレートを使用して実装されたLanguage Server Protocol (LSP)サーバです。

== プロジェクト概要

このプロジェクトは、Rustのtower-lspフレームワークを使用した基本的なLSPサーバの実装です。現在は初期化とシャットダウンのみの機能を持つ最小限の実装となっています。

== 必要な環境

* Rust 1.70以上
* Cargo

== 依存関係

* `tokio`: 非同期ランタイム
* `tower-lsp`: LSPサーバフレームワーク
* `serde`, `serde_json`: JSONシリアライゼーション

== ビルド方法

[source,bash]
----
cargo build
----

== 実行方法

[source,bash]
----
cargo run
----

サーバは標準入出力を使用してLSPクライアントと通信します。

== ACPプロキシとして起動する

同じバイナリに `--acp` を付けると、LSPサーバではなく
ACP (Agent Client Protocol) プロキシとして起動します。
Zedと、普段使っているACPエージェント（Claude Code、Gemini CLIなど）の
あいだに挟まり、会話を素通しさせながら覗き見て、その要約を
LSP側の短文生成のコンテキストとして渡します。

チャットの応答自体は上流のエージェントが作るので、
ツール実行やファイル閲覧のできるエージェントと普段どおり話しながら、
その内容が自動的に補完へ効くようになります。

[source,bash]
----
FIFTY_FOUR_ACP_AGENT='npx -y @agentclientprotocol/claude-agent-acp@latest' \
FIFTY_FOUR_LLM_CONFIG='{"deferred":{"provider":"google"}}' \
fifty_four_lsp --acp
----

`FIFTY_FOUR_LLM_CONFIG` は会話の要約にのみ使います。
Zedへの登録方法（`settings.json` の `agent_servers`）と設定項目は
link:docs/acp-agent.md[docs/acp-agent.md] を参照してください。
