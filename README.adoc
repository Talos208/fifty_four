= fifty_four - LSP サーバ
:toc:
:icons: font

tower-lspクレートを使用して実装されたLanguage Server Protocol (LSP)サーバです。

== プロジェクト概要

このプロジェクトは、Rustのtower-lspフレームワークを使用した基本的なLSPサーバの実装です。現在は初期化とシャットダウンのみの機能を持つ最小限の実装となっています。

== 必要な環境

* Rust 1.70以上
* Cargo

== 依存関係

* `tokio`: 非同期ランタイム
* `tower-lsp`: LSPサーバフレームワーク
* `serde`, `serde_json`: JSONシリアライゼーション

== ビルド方法

[source,bash]
----
cargo build
----

== 実行方法

[source,bash]
----
cargo run
----

サーバは標準入出力を使用してLSPクライアントと通信します。

== ACPエージェントとして起動する

同じバイナリに `--acp` を付けると、LSPサーバではなく
ACP (Agent Client Protocol) エージェントとして起動します。
Zedの Agent Panel から作者とチャットし、その会話の要約を
LSP側の短文生成のコンテキストとして渡します。

[source,bash]
----
FIFTY_FOUR_LLM_CONFIG='{"ondemand":{"provider":"google"}}' fifty_four_lsp --acp
----

Zedへの登録方法（`settings.json` の `agent_servers`）と設定項目は
link:docs/acp-agent.md[docs/acp-agent.md] を参照してください。
